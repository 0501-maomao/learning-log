# 数据清洗笔记

## 一、数据清洗的核心目标

数据清洗不是简单地把“不好看”的数据删掉，而是让数据变得：

- 结构统一
- 类型正确
- 缺失值明确
- 异常值可识别
- 重复数据可处理
- 后续可以分析、建模或统计
- 清洗过程可追踪、可复现

一句话总结：

> 数据清洗的本质，是把混乱的数据整理成符合业务规则、可以被程序稳定处理的数据。

## 二、拿到脏数据后先做什么

不要一上来就写复杂代码。第一步应该是观察数据。

常用检查代码：

```python
import pandas as pd

df = pd.read_csv("data/raw/dirty_customers.csv")

print(df.head())
print(df.info())
print(df.describe())
print(df.isna().sum())
print(df.duplicated().sum())
print(df.nunique())
```

重点观察：

- 数据有多少行、多少列
- 字段名是否规范
- 每一列的数据类型是否正确
- 是否存在缺失值
- 是否存在重复行
- 数字列里是否混入文字
- 日期列格式是否混乱
- 分类字段是否写法不统一
- 是否存在明显不合理的异常值

## 三、常见脏数据问题

### 1. 列名混乱

常见情况：

```text
 Customer ID
customer id
CUSTOMER_ID
Signup Date
```

处理目标：

```text
customer_id
signup_date
```

示例代码：

```python
df.columns = (
    df.columns
    .str.strip()
    .str.lower()
    .str.replace(" ", "_")
)
```

### 2. 字符串中有多余空格

常见情况：

```text
" Alice "
"  Beijing"
"ALICE@example.COM "
```

示例代码：

```python
df["name"] = df["name"].str.strip()
df["email"] = df["email"].str.strip().str.lower()
df["city"] = df["city"].str.strip()
```

如果想处理所有文本列：

```python
for col in df.select_dtypes(include="object").columns:
    df[col] = df[col].str.strip()
```

### 3. 缺失值不统一

缺失值不一定只表现为 `NaN`，还可能是：

```text
""
"N/A"
"na"
"null"
"None"
"unknown"
"-"
```

示例代码：

```python
df = df.replace(["", "N/A", "na", "null", "None", "unknown", "-"], pd.NA)
```

常见处理方式：

- 关键字段缺失：删除或标记人工复核
- 普通文本字段缺失：填 `"unknown"`
- 数值字段缺失：填中位数、均值或 0
- 日期字段缺失：保留为空，或标记为需要复核

### 4. 重复数据

重复数据分两种。

完全重复：

```python
df = df.drop_duplicates()
```

业务重复：

```python
df = df.drop_duplicates(subset=["customer_id"])
```

注意：

如果两行 `customer_id` 一样，但其他字段不一样，不能盲目删除。需要根据业务决定：

- 保留第一条
- 保留最新一条
- 合并字段
- 标记为需要人工复核

### 5. 数据类型错误

常见情况：

```text
age = "28"
age = "unknown"
amount = "1,200.50"
signup_date = "not a date"
```

数字转换：

```python
df["age"] = pd.to_numeric(df["age"], errors="coerce")
```

金额转换：

```python
df["amount"] = (
    df["amount"]
    .astype(str)
    .str.replace(",", "")
)
df["amount"] = pd.to_numeric(df["amount"], errors="coerce")
```

日期转换：

```python
df["signup_date"] = pd.to_datetime(df["signup_date"], errors="coerce")
```

`errors="coerce"` 的作用：

如果转换失败，就把错误值变成缺失值，方便后面统一处理。

### 6. 异常值

异常值是指格式可能没错，但业务上不合理。

例子：

```text
age = 200
age = -5
amount = -99
email = bob[at]example.com
signup_date = 2026-13-01
```

处理年龄异常：

```python
df.loc[(df["age"] < 18) | (df["age"] > 120), "age"] = pd.NA
```

处理金额异常：

```python
df.loc[df["amount"] < 0, "amount"] = 0
```

异常值处理原则：

- 不能确定时不要随便改
- 可以先标记为 `needs_review`
- 有业务规则时按规则处理
- 保留清洗报告，记录处理了多少异常数据

### 7. 日期格式不统一

常见情况：

```text
2026/08/01
2026-08-01
2026.08.01
15/08/2026
not a date
```

统一为：

```text
YYYY-MM-DD
```

示例代码：

```python
df["signup_date"] = pd.to_datetime(df["signup_date"], errors="coerce")
df["signup_date"] = df["signup_date"].dt.strftime("%Y-%m-%d")
```

### 8. 分类字段不统一

常见情况：

```text
yes
YES
1
true
Active
active
no
0
false
```

统一为：

```text
active
inactive
pending
unknown
```

示例代码：

```python
status_map = {
    "yes": "active",
    "1": "active",
    "true": "active",
    "active": "active",
    "no": "inactive",
    "0": "inactive",
    "false": "inactive",
    "inactive": "inactive",
    "pending": "pending",
}

df["status"] = (
    df["status"]
    .str.strip()
    .str.lower()
    .map(status_map)
    .fillna("unknown")
)
```

## 四、推荐的数据清洗流程

看到一个脏数据，可以按这个顺序处理：

```text
读取数据
↓
观察数据
↓
统一列名
↓
清理字符串
↓
识别缺失值
↓
处理重复值
↓
转换数据类型
↓
处理异常值
↓
统一日期、金额、分类字段
↓
标记需要人工复核的数据
↓
输出清洗结果
↓
生成质量报告
```

## 五、一个通用清洗模板

```python
import pandas as pd


def clean_data(input_path: str, output_path: str) -> pd.DataFrame:
    df = pd.read_csv(input_path, dtype=str, keep_default_na=False, skipinitialspace=True)

    # 1. 统一列名
    df.columns = (
        df.columns
        .str.strip()
        .str.lower()
        .str.replace(" ", "_")
    )

    # 2. 清理文本空格
    for col in df.select_dtypes(include="object").columns:
        df[col] = df[col].str.strip()

    # 3. 统一缺失值
    df = df.replace(["", "N/A", "na", "null", "None", "unknown", "-"], pd.NA)

    # 4. 删除完全重复行
    df = df.drop_duplicates()

    # 5. 类型转换
    if "age" in df.columns:
        df["age"] = pd.to_numeric(df["age"], errors="coerce")

    if "amount" in df.columns:
        df["amount"] = df["amount"].astype(str).str.replace(",", "")
        df["amount"] = pd.to_numeric(df["amount"], errors="coerce")

    if "signup_date" in df.columns:
        df["signup_date"] = pd.to_datetime(df["signup_date"], errors="coerce")
        df["signup_date"] = df["signup_date"].dt.strftime("%Y-%m-%d")

    # 6. 异常值处理
    if "age" in df.columns:
        df.loc[(df["age"] < 18) | (df["age"] > 120), "age"] = pd.NA

    if "amount" in df.columns:
        df.loc[df["amount"] < 0, "amount"] = 0

    # 7. 标记需要人工复核的数据
    df["needs_review"] = df.isna().any(axis=1)

    # 8. 输出结果
    df.to_csv(output_path, index=False, encoding="utf-8-sig")

    return df
```

## 六、清洗时要问自己的问题

每处理一列，都可以问自己：

- 这一列应该是什么类型？
- 这一列允许为空吗？
- 空值应该删除、填充，还是保留？
- 有没有明显不合理的值？
- 有没有多种写法表示同一个意思？
- 有没有重复记录？
- 如果自动处理会不会误伤数据？
- 是否需要标记人工复核？

## 七、清洗报告应该记录什么

工程化的数据清洗最好输出一份质量报告。

建议记录：

- 原始行数
- 清洗后行数
- 删除了多少重复行
- 每列有多少缺失值
- 有多少非法邮箱
- 有多少非法手机号
- 有多少异常年龄
- 有多少日期转换失败
- 有多少金额异常
- 有多少行需要人工复核

示例结构：

```json
{
  "input_rows": 8,
  "output_rows": 7,
  "invalid_counts": {
    "duplicate_customer_id_rows_removed": 1,
    "invalid_email": 2,
    "invalid_phone": 1,
    "invalid_age": 3,
    "invalid_signup_date": 2,
    "invalid_amount": 3
  },
  "review_rows": 3
}
```

- 字段名标准化
- 字符串清洗

- `pd.to_numeric()` 数字转换

- 异常值判断

- 生成 JSON 格式的数据质量报告

## 九、最重要的原则

数据清洗没有唯一答案，必须结合业务规则。

例如：

- 年龄为 200，通常是异常值
- 金额为负数，不一定总是错误，可能是退款
- 日期为空，不一定要删除，可能只是还没注册
- 邮箱错误，可能需要人工补录
- 重复客户 ID，不一定删除，可能需要合并记录

所以清洗数据时要记住：

> 能确定的自动处理，不能确定的标记复核，所有处理都要留下记录。
